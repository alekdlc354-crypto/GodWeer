# 🎨 Incredible Visual Effects

Красивые визуальные эффекты для вашего клиента, созданные с любовью к эстетике!

## ✨ Новые модули

### 🌈 Trails (Следы)
Красивые светящиеся следы за движущимися сущностями с множеством режимов.

**Особенности:**
- **6 цветовых режимов:**
  - `Rainbow` - переливающиеся радужные цвета
  - `Gradient` - плавный градиент между двумя цветами
  - `Theme` - цвет из темы клиента
  - `Crystal` - кристальные оттенки
  - `Aurora` - эффект северного сияния
  - `Neon` - яркие неоновые цвета

- **Настраиваемые параметры:**
  - Длина следа (8-50 точек)
  - Ширина следа (0.1-0.6)
  - Скорость затухания
  - Яркость свечения
  - Скорость пульсации

- **Специальные эффекты:**
  - Spiral Mode - спиральные следы
  - Through Walls - видимость сквозь стены
  - Поддержка разных типов сущностей (игроки, живые существа, все сущности)

### 💥 PopEffect (Поп-эффекты)
Невероятные визуальные эффекты для ударов, убийств и срабатывания тотемов.

**Hit Effect (Эффект при ударе):**
- **Explosion** - эпичный взрыв частиц с ударной волной
  - Многослойные частицы с градиентами
  - Спиральные траектории
  - Расширяющаяся ударная волна
  
- **Lightning** - множественные молнии
  - 3 молнии одновременно
  - Ветвящиеся разряды
  - Искры от удара

**Kill Effect (Эффект при убийстве):**
- **Beam** - энергетические лучи
  - 5 лучей, стреляющих вверх по кругу
  - Центральный золотой луч
  - Спиральные частицы вокруг
  - Двойные ударные волны
  
- **Explosion** - массивный взрыв
  - 2x больше частиц
  - Тройные ударные волны
  - Золотые и цветные частицы

**Totem Pop Effect (Эффект тотема):**
- **Spiral** - красивые спиральные кольца
  - 3 вращающихся кольца
  - Золотые и зелёные цвета
  - Частицы, следующие по спирали
  
- **Beam** - золотой луч света
  - Мощный луч высотой 40 блоков
  - Тройная спираль частиц
  - Ударная волна
  
- **Explosion** - эпичный взрыв тотема
  - Классические золотые и зелёные частицы
  - Двойные ударные волны

**Общие настройки:**
- Theme Color - использование цвета темы
- Кастомные цвета для каждого эффекта
- Количество частиц (10-250)
- Размер частиц (0.1-1.2)
- Время жизни (0.3-5.0 сек)
- Скорость анимации
- Яркость свечения
- Through Walls - видимость сквозь стены

## 🎯 Визуальные компоненты

### Частицы (EpicParticle)
- Многослойное свечение (внешнее, основное, ядро)
- Плавное затухание с easing функциями
- Спиральные траектории
- Вращение и пульсация
- Притягивание к цели

### Ударные волны (ShockWave)
- Расширяющиеся кольца
- Плавное затухание
- Настраиваемая толщина

### Энергетические лучи (EnergyBeam)
- Сегментированные лучи
- Трёхслойное свечение
- Плавное появление и исчезновение

### Спиральные кольца (SpiralRing)
- Вращающиеся кольца частиц
- Расширение/сжатие
- Настраиваемая скорость вращения

### Молнии (LightningStrike)
- Ветвящиеся разряды
- Мерцание и вспышки
- Двойное свечение (основное + ядро)

## 🔧 Технические детали

### Рендеринг
- Используется `ParticlesWorldRenderer` для оптимальной производительности
- Additive blending для яркого свечения
- Поддержка рендеринга сквозь стены
- Billboard спрайты, всегда повёрнутые к камере

### Производительность
- Ограничение количества частиц (5000 для trails)
- Автоматическое удаление мёртвых частиц
- Оптимизированные математические операции
- Delta-time для плавной анимации

## 🎮 Как использовать

1. **Trails:**
   - Включите модуль `Trails` в категории Render
   - Выберите цветовой режим
   - Настройте параметры под свой вкус
   - Двигайтесь и наслаждайтесь красивыми следами!

2. **PopEffect:**
   - Включите модуль `PopEffect` в категории Render
   - Выберите эффекты для Hit/Kill/Totem
   - Настройте цвета и параметры
   - Атакуйте мобов/игроков и наслаждайтесь эффектами!

## 🎨 Советы по настройке

**Для максимальной красоты:**
- Включите `Through Walls` для видимости эффектов сквозь стены
- Используйте `Theme Color` для согласованности с интерфейсом
- Увеличьте `Brightness` до 4.0-6.0 для яркого свечения
- Для Trails попробуйте `Rainbow` + `Spiral Mode`
- Для PopEffect используйте `Spiral` для тотемов и `Beam` для убийств

**Для производительности:**
- Уменьшите количество частиц (Count)
- Уменьшите время жизни (Lifetime)
- Отключите `Through Walls`
- Используйте меньшую яркость

## 🌟 Особенности реализации

- Все эффекты используют современную систему рендеринга через GPU
- Полная интеграция с системой событий клиента
- Поддержка mixin для хуков в игровой процесс
- Автоматическое определение смерти сущностей
- Обработка сетевых пакетов для тотемов
